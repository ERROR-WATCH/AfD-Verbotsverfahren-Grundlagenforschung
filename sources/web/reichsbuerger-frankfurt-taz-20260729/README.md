## Status- und Beweisgrenze

Das Frankfurter Staatsschutzverfahren läuft. Die taz dokumentiert eine Einlassung eines Mitangeklagten, keine rechtskräftige gerichtliche Tatsachenfeststellung. Der AfD-Bezug ist eine konkrete frühere Mandats- und Personenkante zu Malsack-Winkemann; daraus folgt keine automatische strafrechtliche oder parteienrechtliche Zurechnung zur Gesamtpartei.
